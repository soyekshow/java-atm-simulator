# Java ATM Simulator

## Overview
A console-based Automated Teller Machine (ATM) simulation engineered with Java. This project serves as a practical demonstration of core Object-Oriented Programming (OOP) principles, specifically focusing on data encapsulation, state management, and secure user authentication.

## Features
* **Encapsulation:** Protects sensitive user data (account balance, PIN) using private access modifiers and public getter/setter methods.
* **Authentication Module:** Implements a secure PIN verification system before granting access to financial operations.
* **Transactional Logic:** Handles real-time deposit and withdrawal calculations while preventing invalid operations (e.g., insufficient funds, negative deposits).

## Technologies Used
* **Language:** Java
* **Concepts:** Object-Oriented Programming (OOP), Control Flow, Scanner Input Handling.

## How to Run
1. Compile the Java file: `javac AtmSimulator.java`
2. Execute the compiled class: `java AtmSimulator`
